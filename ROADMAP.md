# SurfaceBend Roadmap

## Current Direction

SurfaceBend should evolve into a URL-to-living-interface prototype where web layouts feel tactile, layered, and responsive.

## Near-Term Improvements

- tighten hero layout and visual hierarchy
- improve mobile behavior for panel previews
- add more convincing panel depth and lighting
- improve CTA clarity and product framing
- add stronger empty and loading states

## Next Features

- real URL capture flow
- captured section selection
- richer surface motion and hover response
- panel rearrangement or layout presets
- basic shareable preview state

## Add-Ons

- alternate visual themes
- exportable concept snapshots
- motion intensity controls
- comparison mode between two surfaces
- prompt-assisted scene suggestions

## Good To Have

- subtle sound or haptic-inspired cues
- short guided onboarding
- template gallery for example websites
- presentation mode for demos
- lightweight analytics for shared previews

## Production Readiness Later

- capture pipeline reliability work
- error states for unsupported URLs
- proper environment config
- performance profiling for richer animation
- deployment config and domain setup
